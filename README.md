# Suspicious Login Attempt Detector 

An automated cybersecurity monitoring tool built with Python to analyze authentication logs, detect brute-force attack patterns, and identify anomalous login behaviors.

## Features
* **Authentication Log Analysis:** Parses and inspects system login logs.
* **Brute-Force Detection:** Identifies multiple failed login attempts from single or distributed IP sources.
* **Alerting System:** Triggers alerts upon detecting suspicious access patterns.

##  Tech Stack
* **Language:** Python
* **Domain:** Cybersecurity & Threat Detection
* **Core Skills:** Log Analysis, Security Monitoring, Cyber Threat Detection

##  How It Works
1. **Data Ingestion:** Reads log entries containing timestamps, user IDs, and IP addresses.
2. **Rule Analysis:** Checks thresholds for failed login attempts within specified time windows.
3. **Detection Output:** Generates structured security alerts for identified threat patterns.
